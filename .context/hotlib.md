# HotLib Flow

## Overview

The hot-reload system is built on **dynamic libraries (`.so`)** + **function-pointer
tables** to swap code at runtime without restarting. Core engine lives in
`src/hotreload/hotlib.rs`; proc-macro codegen lives in `packages/hotfnl-proc-macro/lib.rs`.

## Architecture

### `HotLib` (singleton, `src/hotreload/hotlib.rs`)

- `lib: AutoLib` — circular 3-slot store of loaded libraries; adding a new lib closes the old one.
- `functions: Arc<RwLock<Vec<fn()>>>` — the active function-pointer table.
- `functions_dict: BTreeMap<String, u16>` — maps key `file:name` → index into the table.
- `layout_dict: BTreeMap<String, u64>` — maps struct key `file:name` → compile-time content
  hash of its definition (baseline, from `#[hot_layout]`).
- `backup_functions: Vec<fn()>` — original boot-time pointers, used as patch baseline.
- `tx` — channel sending `HotLibAction` to the background watch loop.
- `event` — lifecycle callbacks registry.

### Singleton pattern

- `DEFAULT_INSTANCE: OnceLock<Arc<Option<Arc<RwLock<HotLib>>>>>`
- `INSTANCE: LazyLock<Arc<RwLock<HotLib>>>`
- `rewrite_instance(old)` — sets `DEFAULT_INSTANCE = Some(old)`, letting a newly loaded
  library adopt the host's instance (lines 129-131).

## Boot flow

On app start, `#[hot_main]` (generated) calls `hotfnl::boot(...)`:
- Collects `HotFn` list from `inventory`.
- Collects `HotLayout` list (struct fingerprint hashes) from `inventory`.
- `on_boot()` builds `functions_dict` (duplicate key → panic), `layout_dict`, and `backup_functions`.
- `run_watch_lib()` spawns a thread listening on a Unix datagram socket, receiving
  `HotProjectState` from the build process:
  - `SourceChanged` → `on_source_changed`
  - `Rebuilding` → `on_pre_rebuild`
  - `BuildSuccess(version)` → load lib path by version → `get_lib()` → `apply_lib()`
    - success → `on_patch_success`
    - `FailedLoadLib | NoFnGetFunctions | OtherError` → `on_patch_error`
    - `ToManyChange | FailedCleanLib` → `std::process::exit(0)`
  - `BuildFailed` → `on_rebuild_error`

## `hrl_get_functions` (generated by `#[hot_main]`, `packages/hotfnl-proc-macro/lib.rs:63-75`)

```rust
#[unsafe(no_mangle)]
pub extern "C" fn hrl_get_functions(lib: Arc<RwLock<hotfnl::HotLib>>) -> Vec<hotfnl::HotFn> {
    // collect HotFn via inventory
    hotfnl::HotLib::rewrite_instance(lib); // ← adopts host instance, overwrites singleton
    list_fn
}
```

The new library receives `Arc<RwLock<HotLib>>` from the host and calls
`rewrite_instance(lib)` to point at the **same** `HotLib` as the host process (not a new one).

## `#[hot_fn]` macro flow (`packages/hotfnl-proc-macro/lib.rs:102-199`)

Input:
```rust
#[hot_fn("module")]
fn add(a: i32, b: i32) -> i32 { a + b }
```

Generated:
```rust
#[unsafe(no_mangle)]
fn add(a: i32, b: i32) -> i32 {
    static FN_NAME: &str = "module::add::(i32, i32)->i32";
    static FILE_NAME: &str = file!();

    fn cb(a: i32, b: i32) -> i32 { a + b }          // original function renamed to `cb`

    static IDX: LazyLock<u16> =
        LazyLock::new(|| hotfnl::get_fn_idx(FN_NAME, FILE_NAME)); // table index

    let callback_list = hotfnl::get_fn_list::<fn(i32, i32) -> i32>(); // typed table

    hotfnl::inventory::submit! {
        crate::hot::HotFn {
            func: unsafe { std::mem::transmute(cb as *const()) },
            fn_name: FN_NAME,
            file_name: FILE_NAME,
        }
    }

    let guard = callback_list.read().unwrap();
    let result = guard[*IDX as usize](a, b);        // dispatch via table, NOT `cb` directly
    drop(guard);
    result
}
```

Notes:
- Only named arguments are supported — non-Ident patterns → compile error.
- Receivers (`self`) not supported for free functions; methods use
  `#[hot_impl]`/`#[hot_method]`.
- `cb` is transmuted to `fn()` at submit; cast back to the real type when dispatching.

## Reload / Patch flow

1. Build process compiles a new library → sends `HotProjectState::BuildSuccess(version)` over a socket.
2. Watch loop calls `HotLib::get_lib(lib_path)` (`hotlib.rs:194`):
   - Loads `.so` (`PatchErr::FailedLoadLib` on failure).
   - Resolves `hrl_get_functions` symbol (`PatchErr::NoFnGetFunctions` if missing).
   - Calls `hrl_get_functions(INSTANCE.clone())` → new library calls `rewrite_instance`.
   - Merges new `HotFn`s into a copy of `backup_functions` by key; if a key doesn't match
     (added/removed functions) → `PatchErr::ToManyChange` and closes the lib.
   - Resolves `hrl_get_layouts` (optional; older libs are exempt). Compares each struct's
     content hash against the boot-time `layout_dict` by key `file:name`. A missing key,
     extra key, or hash mismatch (struct layout changed) → `PatchErr::ToManyChange` and
     closes the lib, which makes the app exit so the wrapper respawns a freshly built binary.
3. `apply_lib(lib, list_fn)` (`hotlib.rs:237`):
   - Runs `on_clean_up` callbacks (against old table, before the swap).
   - Writes new `list_fn` into `functions`.
   - `AutoLib::add(lib)` — stores the new lib, closes the old one (failure → `FailedCleanLib`, exit).
   - `on_patch_success`.

## Helpers

- `get_fn_idx(fn_name, file_name)` (`hotlib.rs:317`) — panics if the key is unknown.
- `get_fn_list<T>()` (`hotlib.rs:332`) — transmutes `Vec<fn()>` → `Vec<T>`; **unsafe**,
  caller must guarantee type layout matches.

## `#[hot_layout]`

Marks a struct whose layout must stay stable across reloads:
- Proc macro fingerprints the whole struct definition (fields, types, generics, attrs)
  with FNV-1a 64 and submits `crate::hot::HotLayout { file_name, struct_name, hash }`
  via `inventory`.
- `#[hot_main]` exports `hrl_get_layouts() -> Vec<HotLayout>` from the loaded library.
- In `get_lib`, each fingerprint must match the boot-time `layout_dict` exactly
  (same key + hash), else `PatchErr::ToManyChange` → app exits and the wrapper respawns
  the freshly built binary.

## Invariants

- The function SET must not change across reloads (added/removed entries → `ToManyChange`).
- Each `#[hot_fn]` needs a unique `file:name` key at boot (duplicate → panic).
- Dispatch type must exactly match between the `fn()` table and the type passed to `get_fn_list`.
